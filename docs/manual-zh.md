# Squad 间瞄火力助手（桌面版）

把网页版《载具通行性地图》里的「间瞄火力计算 / 快速校准炮击」搬成独立桌面程序，再加一层
**AI 识图**：切回游戏按热键，程序自动截取屏幕上的 CURRENT GRID 区域，认出目标网格坐标，
结合你在地图上点出的迫击炮阵地，直接算出**密位**与**方位角**，半透明浮窗盖在游戏上。

1.3.0 起「间瞄火力支援」分成 **无人机视角** 与 **望远镜视角** 两个子模式：前者只要目标坐标，后者才读你视角的方位角；
两个子模式的**截图框、区域预设、热键各自独立**，互不干扰。地图也加了**同款 4 级网格**与左上角「查坐标」按钮。

1.4 起又加了**侦察报告**，1.7 再加第三模式 **「发布命令」**：选好我方阵营与具体部队，用小键盘走完
「队长 → 4 级坐标 → 任务（含建造子菜单）→ 态度」四步，自动把
「2队长，你去G07-5-3-6执行建造HESCO 掩体任务，立即执行」这样的整句复制进剪贴板并显示在浮窗。

## 二、第一次使用（三步设置）

1. **DeepSeek 密钥**：填进「DeepSeek 密钥」框 → 点「保存」。
   密钥存在同目录 `config.json`（明文，只在本机；不想留就删掉这个字段）。
   模型固定 `deepseek-flash`（DeepSeek-V4.1-Flash，支持读图）。
2. **先选间瞄子模式，再框截图区域**：面板「间瞄子模式」两个按钮二选一，
   每个子模式有自己的一套框、预设与键位（切过去只显示这一套）：

   - **无人机视角**（默认）—— 要 **① 目标坐标区域**：点「框选坐标区域」，屏幕变暗后
     **只框住 HUD 里 CURRENT GRID 那两三行字**（框里别放血条、图标、地图，越干净越准）。
     **可选 ② 方位角区域**（1.8.6 起）：无人机画面上的方位 / 航向读数那几位数字。
     框了它，「快速定位」就变成两步（同一个热键按两次）：**指挥官无人机先读目标坐标、再读方位角**（1.8.16 起 —— 它一直在盘旋、方位角时刻在变，小地图要用最新的那一次），**侦察兵无人机反过来先读方位角**；两步自动衔接，读完就弹一张 60 m 小地图
     （正上方 = 你读到的方位），见下面「无人机视角的快速定位」。**指挥官无人机与侦察兵无人机的
     方位角框分开存**（面板里那个下拉切换），因为两台机器的 HUD 位置不一样。不框也能用，
     只是退回老样子：截 1 次坐标直接当目标、不弹小地图。
   - **望远镜视角** —— 要两块：**① 玩家坐标区域**（HUD「玩家位置：」那几行）+ **② 方位角区域**
     （点「框选方位角」时**只框屏幕上那几个方位角数字**，269、051 这种，别把整条刻度带框进去）。

   用「侦察报告」模式的话，它还有**自己的一套子模式与框**（无人机视角 2 块 + 可选 1 块方位角 /
   望远镜视角 2 块，见下面「侦察报告」一节），和这里互不影响（无人机方位角那块是**共用**的，见 1.8.9）。

   每块都有「预览截图」确认自己框到哪儿了。框的时候右键 / Esc / 框得太小都算取消：
   **主界面会自己回来，原来的区域不变**。
   同一个子模式的两块可以**一起存成预设**反复用，见下面「区域预设」。
3. **选地图 + 选武器 +（可选）选弹道**：地图 25 张官方图全在；武器 **42 组**（部署 16 + 车载 10 + 常见模组 16）。
   武器下面那一行是 **「弹道」自动 / 低抛 / 高抛**（1.12.0 起）：同一门炮打同一组坐标，可以指定走平射那一支还是
   大仰角那一支解，默认「自动」= 按武器自己的习惯（跟以前一样），细节见第六章。
4. **（可选）改热键**：每个子模式有自己的几行热键，点一下右边的输入框，直接按下你想用的键即可——
   支持 **F1–F24、字母、数字**，也能加 **Ctrl / Shift / Alt**（例如 F8、Ctrl+Shift+D、Alt+Q）。

   **无人机视角（默认子模式）**

   | 功能 | 默认键 | 干什么 |
   |---|---|---|
   | **快速定位** | **F1** | 框了「方位角区域」时是两步：**指挥官无人机 ① 读目标坐标 → ② 读方位角**（1.8.16 起，方位角要用最新的）、侦察兵无人机 ① 读方位角 → ② 读坐标，两步自动衔接，读完弹 60 m 小地图让你点真实位置（1.8.6 起）；没框就还是只截 **1 次**目标坐标直接当目标（快，适合移动目标/应急） |
   | **准确定位** | **F2** | 连截 **3 次**目标坐标，取三点外心再算（准，抵消单次读数抖动） |
   | **清除坐标** | **F3** | 清掉**已截但还没算成目标**的坐标；上次算好的目标**保留不动** |
   | **浮窗显隐** | **F4** | 显示 / 隐藏半透明浮窗 |

   **望远镜视角**

   | 功能 | 默认键 | 干什么 |
   |---|---|---|
   | **望远镜流程** | **F8** | 按一次读你视角的方位角，再按一次读你自己的坐标，然后小键盘补位与输距离 |
   | **清除望远镜** | **F9** | 清掉走了一半的望远镜流程；上次算好的目标保留 |
   | **浮窗显隐** | **F10** | 显示 / 隐藏半透明浮窗 |

   **侦察报告**（两个子模式共用这四个键）

   | 功能 | 默认键 | 干什么 |
   |---|---|---|
   | **标记 / 下一步** | **F5** | 无人机视角：截敌目标坐标；望远镜视角：读方位角 → 读你的坐标 → 输距离 |
   | **报告** | **F11** | 选一条已记目标 + 连打队友坐标，算出「敌人相对队友的方位与距离」 |
   | **清除侦察** | **F6** | 清掉走了一半的侦察流程；目标库里的记录保留 |
   | **浮窗显隐** | **F7** | 显示 / 隐藏半透明浮窗 |

   三套键**默认各不相同**，但**允许设成同一个键**：同一个键绑在几套上时，程序按「当前在哪个模式 / 子模式」
   决定做什么（例如三套流程键都填 Shift+F1：无人机视角下是快速定位，望远镜视角下是望远镜流程，
   侦察报告下是侦察流程）。如果这个键只在别的模式里绑过，本模式会提示「这个键只绑在…上」。
   按下即生效并写进 config.json，下次启动仍然是你设的键。
   - 改完会同步到界面上所有提示（副标题、按钮文案、玩法说明）。
   - 新键被别的程序占用时，下面提示行会变红「注册失败（错误码 1409…），换一个组合试试」，
     此时仍可点面板上的按钮照常工作。
   - 同一套里的键**不能重复**（例如无人机视角里「快速定位」和「清除坐标」都填 F1，会红字提示并回退）；
     不同模式之间**可以**共用同一个键。
   - 不建议用**单个字母**：全局热键会抢走这个键，游戏里打字、聊天都会误触发，建议加 Ctrl/Shift。

### 区域预设（保存 / 改名 / 删除 / 套用）

**每个子模式各有一份预设列表**（无人机视角的预设不会出现在望远镜视角里，反之亦然）。

「截图区域」分组里有一行 **「区域预设」下拉 + 保存当前 / 重命名 / 删除**：

- **保存当前**：把**这个子模式现在的框（坐标 + 方位角，望远镜是玩家坐标 + 方位角）一起**存成一条预设，
  只框了其中一块（比如只框了方位角）也能单独存；套用时只覆盖预设里有的那块，另一块保持现状。
  弹框输入名字（同名会覆盖）。默认名是「区域 1」「区域 2」…… 也可以自己起，比如「我的 HUD」「2K 准星区」。
- **重命名**：给下拉里选中的那条预设改名；重名会被拒绝并提示。
- **删除**：确认后删掉选中的那条；当前框选区域本身不动，只是去掉这条记录。
- **套用**：在下拉里选一条，**坐标区域和方位角区域一起换过去**，状态行写「· 预设「名字」」。
  手动重新框选后状态行变「· 未保存」，表示这条区域还没存进预设。

无人机视角的预设除了坐标框，还会把**指挥官 / 侦察兵两台无人机的方位角框**一起存下来（1.8.6 起，
`rect_az_cmd` / `rect_az_scout`）—— 换机器或换分辨率时套一条预设，三块框一起到位。

预设存在 `config.json` 里：无人机视角是 `regions`，望远镜视角是 `s_regions`（每项 = 名字 + 坐标矩形 + 方位角矩形），
换分辨率或换显示器后框一遍、用同名「保存当前」覆盖即可。
从 1.2.x 升上来时，原来的 `region` / `region_az` 会自动复制一份给望远镜子模式（同一个 HUD 位置），
所以望远镜那边通常开局就能直接用，不用重新框。

然后**在地图上点一下** = 设迫击炮阵地（会显示格号与高程，右键清除，滚轮缩放，按住左键拖动平移）。

## 三、游戏内怎么用

1. 开局先在游戏里看好自己架炮的格子，回到本程序在地图上点出来（只用点一次，之后一直有效）。
2. 切回游戏，把准星对着目标（HUD 上 CURRENT GRID 显示目标格），然后按：

   - **快速定位（默认 F1）**：只截 1 次，这个坐标直接当目标，浮窗立刻出密位/方位。
   - **准确定位（默认 F2）**：连截 3 次——**再挪一点点准星，按第 2、第 3 次**，
     程序把 3 个读数合成一个目标点（三点外心；两点相同取中点；三点相同按单点），
     抵消单次识别的读数误差（详见下面「三次截取取外心」）。

   截错了、或者 3 次没凑齐就不想继续了：按 **清除坐标（默认 F3）**，已截的作废，
   上次算好的目标原样保留。
3. 浮窗立刻给出**状态**和四个值：

   | 行 | 内容 |
   |----|------|
   | **状态**（最上面一行，带彩色圆点） | 🟡 **识别中 · 快速定位（1 次）** / **截第 n 个（n/3）· 正在识别**（点会跳动）→ 🟢 **计算完成 · 目标格号** / 🔴 **计算失败（原因）**；准确定位只截了 1~2 个时是灰点「①② 已记 X · 等第 3 个（3/3）」，没开始算时是「待命 · F1 快速 / F2 准确」 |
   | 阵地 | 你点的阵地格号 · 高程 |
   | 目标 | AI 从截图里认出的目标格号 · 高程；准确定位还没凑齐 3 个时显示「① K12-1-8（1/3）」这类进度 |
   | 密位 | 迫击炮/火炮该装的密位（mil） |
   | 方位 | 阵地→目标的方位角（°）——**固定在最下面一行** |
   | 底部小字 | 射角（武器自己的单位）、飞行时间、距离，或「不可达 / 小于最小射程」等提示 |

   看到 🟡 就是在等 AI 回话（通常 1～2 秒），看到 🟢 才是这次算成了。

4. **密位 + 方位会自动进剪贴板**：算出诸元的那一刻，程序把 `密位 1353.09 方位 63.9°` 这样的整句复制到
   系统剪贴板（单位不是 mil 的武器写成 `射角 6.71° 方位 63.9°`），浮窗底部小字与面板来源行末尾同时追加
   「· 已复制」。切回游戏在小队频道 `Ctrl+V` 就能直接把炮令发出去，不用手抄。
   打不到（超射程 / 射界外 / 弹丸寿命外）时**不会**写剪贴板，也不会留下上一次的旧诸元 ——
   免得把一组已经不对的炮令粘到频道里；准确定位只截了 1~2 个的时候同样不会提前复制。

### 地图上的 4 级网格与「查坐标」

地图左上角有四个小按钮：**「查坐标」**、**「网格」**（默认开着）、**「旗点」**（1.8.11 起）和 **「计时」**（1.8.12 起）。

- **网格**：把整套 4 级网格画在底图上，随缩放逐级显现，不用开游戏也能换算格号：
  - 300 m 主格（实线，够大时左上角写 `H8` 这种主格号）；
  - 100 m 格 → 100/3 m 子格 → 100/9 m 子格（点线），最细一级就是望远镜流程里说的「第 4 段」。
  - 缩得越小只会显示粗的那几级，免得糊成一团；不想要就点一下「网格」关掉。
- **查坐标**：弹一个输入框，直接输 4 级坐标（`B11-2-5-6`；只输 3 级 `B11-2-5` 也行，
  会落在该格中心），地图立刻**居中放大**到那个位置，画一个**紫色十字**，旁边标
  「`K12-1-8-6 · 149 m`」（格号 + 高程）。
  输入框里还会写明这张图的格子范围（如「这张图（Manicouagan）的网格范围：A1 – N14」）。
  **输错不再没反应**：格式不对、或者格号不在这张图上时，会**弹出提示框**说清原因和
  这张图的有效范围，关掉后输入框里还留着你刚打的字（自动选中），改一下再回车即可；
  面板状态行同时变红留一条同样的提示。
- 鼠标在地图上移动时，右下角实时显示光标处的 **4 级格号 + 高程**，方便对着游戏里的读数核对。
- 地图上的点含义：黄圈 = 阵地、青点 = 目标（3 级）、绿点 = 我（望远镜/侦察）、
  蓝点 = 队友（侦察）、紫十字 = 查坐标定位出来的查询点。

### 旗点 · 占领区（1.8.11）

点地图左上角的 **「旗点」**，右上角弹出「旗点 · 占领区」面板，把游戏里那一局的**旗点位置和占领区大小**
直接画在底图上（数据来自 Yehorivka-Passability 0.50.0 的地图包，25 张图共 3360 个旗点）。

- **图层**下拉：这张图有哪些模式/版本（AAS 进攻 · v1（7 点）、RAAS 随机链 · v1（62 个链位点）、入侵 · v1 …），默认选第一个；
- **进攻链**下拉（只有 RAAS 有）：全部旗点 / Alpha 链（7 个节点）/ Bravo 链…；选单链时序号是链内顺序（1、2、3a、3b…），选「全部旗点」时是链字母 + 节点号（A1、B3）；
- 四个开关：**占领区**（画圆 / 矩形 / 胶囊占领范围）、**中文名**、**英文名**、**序号**；
- 点图上的旗点徽章（**16 px 以内**）就选中它：面板下方写出「旗点 4a · 舍甫琴科（Shevchenko）｜占领区：圆 Ø200 m｜世界坐标 -1428 / 1456｜格号 G16-1-6-1」，
  占领区描成亮黄；**点旗点不会挪你的阵地**（点空处才放阵地）；
- 点面板列表里的任意一行同样选中，并**居中放大**到那个旗点；双击图上的旗点也居中；
- 再点一次「旗点」按钮收起面板和所有旗点标记（状态栏会提示「已收起旗点」）；
- 有些图（如 jensen）包里没数据：面板写「本图没有旗点数据」，列表空，不影响其他功能；
- 性能：一屏几十上百个旗点时，名称标签与序号徽章会预先烤成图片、整层再叠一层离屏缓存，
  平移缩放不会掉帧（实测静态重绘 10 ms 左右、平移一帧 23 ms）。

### 计时（1.8.12）

地图左上角第 4 个按钮 **「计时」**：点一下就从 `00:00:00` 开始往上走（**小时:分钟:秒**），按钮变成高亮的
「结束」；**再点同一个按钮就结束计时**。计时**没有暂停**，只有开始和结束两种状态。

- 时间实时显示在**浮窗第一行**（橙色大字，左边写「计时」）；浮窗被 F3 收起时它照样在后台走，
  重新显示出来还是当前时间；
- 结束那一瞬间变成绿色的「已结束 · 总用时」，在浮窗上**保留 6 秒**再自动收起来，状态栏也留一句用时；
- 跟别的流程互不干扰：读坐标、算诸元、弹小地图、切模式、切到侦察报告，计时都在走，浮窗第一行也一直在；
- 换地图、重新点阵地都不影响；**退出程序**时自动停掉，不写盘（下次启动还是从 `00:00:00` 开始）。
- 用途：记「炮击间隔」「这一轮齐射打了多久」「还要等多久冷却」这类需要盯住的时间。

### 高清地图（8192 × 8192）：全部打包进 exe（1.8.8）

1.8.8 起底图换成 combat_ai 里的 **8192 × 8192** 高清图，而且 **25 张图全部打包进 exe**：发人只给一个 exe，不用再带地图目录。打包之前，这些图先由 `tools\build_mapdb.py` 归拢成一个地图库目录 `dist\mapsdb\`（约 444 MB），再用 PyInstaller 的 `--add-data` 塞进 exe：

```
exe 里（=_MEIxxxx\mapsdb，解压出来的临时目录）
├─ _db.json                库清单（format / 25 张的名字、像素、米/像素、字节数）
├─ <slug>_hq.jpg           8192² 全分辨率（每张 5.4~26.3 MB）
├─ <slug>_elev.png         1024² 高程图
└─ _lo\<slug>_lo.jpg       2048² 缩略图（切图时先顶上，几十毫秒）

程序目录\
├─ Squad间瞄火力助手.exe   约 498 MB（其中地图约 444 MB）
└─ config.json / run.log / targets.db …
```

**清晰度**：旧底图是 2048²，一张 6350 m 的图 1 px ≈ 3.1 m；现在 8192²，**1 px ≈ 0.16 m（sumari）～0.84 m（skorpo）**，树、房子、路沟都看得出来。主界面和两种小地图（望远镜 120 m / 无人机 60 m）用的都是这张高清图；小地图受窗口大小限制，屏幕上 120 m 那张 1 px ≈ 0.37 m、60 m 那张 ≈ 0.24 m。

**代价**：exe 从 56 MB 涨到 **约 498 MB**（522,553,101 字节）。onefile 每次启动都要把包里的东西解到 `%TEMP%\_MEIxxxx`，所以**双击后约 6~8 秒才见窗口**（1.8.6 的 109 MB 版本约 2 秒；实测 `run.log` 首次写盘 5.7~6.5 秒、窗口 7.4 秒）。这是「地图全塞进单文件」的必然开销，不是卡死；嫌慢见下面的「想瘦身」。

**加载方式**：切地图时先把 `_lo` 缩略图贴上来（感觉上是立刻出图），8192² 在后台线程解，**约 1～2.5 秒**后自动换成全分辨率（`run.log` 里有一行 `[map] mutaha · 底图 8192×8192 (高清库) · 1 px ≈ 336 mm`）。整张图缩得很小看的时候仍然用缩略图（屏幕 1 px 要采 8 个以上底图像素时换 8192² 没有意义、还慢）；放大细看就是全分辨率。同一时刻只解一张，连着切图不会攒一堆线程把内存吃满。

**重建 / 换库**：

```bat
python tools\build_mapdb.py --src D:\mil-ai\combat_ai\maps --dst "dist\mapsdb"
```

脚本把 `<slug>_hq.jpg` 与 `<slug>_elev.png` 复制过去，再用 PIL 的 `draft()` 快速解 1/4 后缩出 `_lo` 缩略图，最后写 `_db.json`；25 张约 23 秒、444 MB。地图元数据（图幅、网格原点）仍留在 exe 内的 `data\maps.json`，库里只管图片，所以换库不会把图幅搞乱。

**想换库 / 想瘦身**：库不一定非用 exe 里那套，**在 exe 旁边放一个 `mapsdb\` 目录就会优先用它**（查找顺序 `ARTY_MAPDB` 环境变量 → 程序目录\mapsdb → 源码树的 dist\mapsdb → exe 内的打包资源）。要更小的包，就用 `build_mapdb.py` 造一个只有 4096² 或 `_lo` 的库（把 `--add-data "…\dist\mapsdb;mapsdb"` 换成那个小库）——体积和启动时间按比例下降，代价是清晰度。

**没有库的时候**：退回 `data\maps` 里的 2048² 旧底图（只有源码树里还有，exe 里不打包）；两样都没有，地图区会写「底图读不出来：…」，不会白屏。

### 三次截取取外心（让目标坐标更准）

单人识图每次读数会有一两个子格的抖动，所以默认连截 **3 次**，合成一个目标点：

| 3 个读数的情况 | 算法 | 浮窗底部注明 |
|---|---|---|
| 三个坐标**互不相同** | 取三点构成的三角形的**外心** | 「· 三点外心」 |
| 有**两个**坐标相同 | 相同的两个算一个，与剩下的那个取**中点** | 「· 两点中点」 |
| 三个坐标**全相同** | 按**单点**（就是之前的方法） | 「· 三次一致」 |
| 三点几乎共线、外心算到很远 | 安全兜底：改用三点**重心**（外心离重心超过「60 m 与 6 倍最大边长」取大者才算数） | 「· 三点重心」 |

流程与提示：

| 动作 | 浮窗状态 | 目标行 |
|---|---|---|
| 第 1 次按**准确定位键** | 🟡 截第 1 个（1/3）· 正在识别 → ⚪ ① 已记 K12-1-8 · 等第 2 个（2/3） | `① K12-1-8（1/3）` |
| 第 2 次按**准确定位键** | 🟡 截第 2 个（2/3）· 正在识别 → ⚪ ①② 已记 K12-3-4 · 等第 3 个（3/3） | `② K12-3-4（2/3）`，底部列出已记的两个 |
| 第 3 次按**准确定位键** | 🟡 截第 3 个（3/3）· 正在识别 → 🟢 计算完成 · K13-4-3 | 最终格号 · 高程 |

- 3 次都要求准星对着**同一个目标**，只是轻微挪动一点，让读数来自不同采样点。
- 中间某次没读到坐标时（红字「第 2 个没读到 · 再截一次」）**已记的不会作废**，直接再按一次补上。
- 想反悔：按 **清除坐标键（默认 F3）** 或点面板上的 **「清除已截坐标」**，已记的几个作废；
  **上一次算好的目标会保留**（正在凑新目标时它只是暂时让位，清完就回来）。换地图会自动清空已截的。
- 手动在面板里写目标格（自测/校准用）走单点逻辑，不参与外心。

- 浮窗**半透明底 + 不透明文字**，可以鼠标拖动换位置（位置记进 config.json）；
  **双击浮窗 = 主界面回来**（找不到主界面时用这个）；右键浮窗有菜单：显示主界面 / 隐藏浮窗 / 回到默认位置；
- **F4**（默认）显示/隐藏浮窗；浮窗上右键也可隐藏或回到默认位置；
- 截图里没有坐标时，浮窗「目标」显示「无坐标」并给出提示，不会乱算；
- 面板上的 **「快速定位（F1）」「准确定位（F2）」** 两个按钮等同按对应热键，方便调试。
- 右侧面板底部的红色 **「退出程序」** 按钮：注销全部四个全局热键（还给系统）、关掉浮窗、保存配置，
  然后**完全退出**进程（任务管理器里不会残留）。每次识别之后如果不想要浮窗了，也可以直接用它收工。

### 望远镜火力支援（按一个键走完全流程）

**前置：子模式切到「望远镜视角」，两块区域各框一次** —— ① 玩家坐标区域（HUD「玩家位置：」）、
② 方位角区域（只框那几个数字）。之后 **望远镜流程键（默认 F8）** 按顺序走完四步，
每一步浮窗都会写清楚现在要干什么、下一步按什么：

| 步 | 程序在干什么 | 浮窗状态 | 你要做的 |
|---|---|---|---|
| 1 | 截 **方位角** | 🟡 识别方位角（1/3）→ ⚪ ① 按 F8 截取你视角的方位角（1/3） | 望远镜对准目标，按一次 F8 |
| 2 | 截 **玩家自己的位置**（HUD「玩家位置：」） | 🟡 识别你的坐标 → ⚪ ② 方位 269° 已记 · 再按 F8 截你自己的位置坐标（2/3） | 再按一次 F8 |
| 3 | 等玩家补 **第 4 段子格** | ⚪ ③ 按小键盘 1–9（主键盘也行）补全坐标最后一位：`D3-9-1-?` | 看一眼子格数字，按对应数字键（小键盘，或笔记本主键盘上排） |
| 4 | 等玩家输入 **3 位距离** | ⚪ ④ 用小键盘输你到目标的距离（3 位，百→个，如 155 / 090 / 001）：已输 0/3 | 连按三个数字：`155`、`090`、`001`（小键盘或主键盘都行） |

- 方位角 + 距离 + 自己位置 ⇒ 程序算出敌目标格号（`D3-9-1` + 方位 `269` + 距离 `155` ⇒ `D3-8-3-8` 这类），
  地图上标绿点「我 …」并拉一条绿虚线到敌目标，浮窗给迫击炮 **密位** 与 **方位**。
- 数字**小键盘和主键盘上排都认**（1.8.5 起）：等你输数字的那几步，小键盘 0–9 与主键盘 0–9 一起被临时抢占，
  按完自动还给系统，**不会漏进游戏聊天框**；不输数字的时候这两排都还是系统的，照常打进游戏。
  （1.2.2–1.8.4 只认小键盘，笔记本没有小键盘、或 NumLock 关着时会「按了没反应」，所以放开了主键盘。）
- 小键盘要能被识别，**NumLock 灯必须亮**（灯灭时小键盘发的是 Home/End/方向键）。程序在等你输数字期间会一直盯着 NumLock：
  灯一灭就把提示行标红写「⚠ NumLock 没开」，点亮后自动变回「正在用小键盘输数字」。
  主键盘数字**不受 NumLock 影响**，小键盘灯灭时直接用主键盘上排就行。
- 第 4 段子格是 HUD 没给出的那一级（300 m 主格 → 3 段子格 → 第 4 段约 3.7 m），所以让玩家看一眼补上。
- 距离就是测距仪/望远镜读数（3 位米）。
- **玩家自己在散布圈里**时：算完若你的位置落在弹着点散布椭圆内，状态行加「⚠ 散布圈内」、底部写
  「你在散布圈内（离弹着点 N m）」，**密位与方位照常显示**——只是提醒你别炸到自己。
- **输错可按「⌫ Backspace」删一位**：在第 3 步（补第 4 段）或第 4 步（输距离）按错数字，按一下删掉刚按的那个，
  再重新按；距离已全部删掉后会退回第 3 步，让你重补子格。没在输入的时候按 ⌫ 不会影响游戏。
- 中途放弃：按 **F9（清除望远镜）** 或面板「取消望远镜流程」⇒ 流程清空，**上一次算好的目标保留**。
- 方位角请框 **只含数字的那一小块**（`269`、`051`），别把整条刻度带框进去（模型读单个数字最准）。
- **距离超过 100 m** 时，输完距离会再弹一张小地图让你修正目标（见下一节「距离超过 100 m：浮窗弹小地图」）；
  100 m 以内按规则**不弹**，但状态行会明写「（距离 ≤100 m，没弹小地图）」，免得你以为是程序没反应。

> **1.2.2 改动：数字输入只认小键盘**（望远镜流程这一条已被 1.8.5 放开，见下一条）。侦察流程的「输距离 / 队友坐标里的数字位」
> 一律改为 **右侧小键盘 0–9**（虚拟键 0x60–0x69）；望远镜流程在 1.2.2–1.8.4 也只认小键盘，主键盘上排照常打进游戏。
> 小键盘需要 **NumLock 亮**；等输入期间程序每 1.2 s 检查一次灯，灯灭就在面板提示行标红提示。
> 字母（侦察队友坐标的 A–Z）仍用主键盘。

> **1.8.5 改动：主键盘数字也能走完望远镜流程**。以前只认右侧小键盘，笔记本键盘没有小键盘、或者 NumLock 没开时，
> 第 3 步（补第 4 段）与第 4 步（输距离）会一步也走不下去，看起来就是「按了没反应」。现在这两步把小键盘与主键盘上排
> 一起抢占（输完照旧还给系统）。注意第 4 段子格仍然**只有 1–9**（那一级就是 9 宫格），按 0 会被忽略。

> **1.2.3 改动：「⌫ Backspace」删掉刚输入的一位**。所有需要手动输入的步骤（望远镜的补第 4 段 / 输距离、侦察的输距离 /
> 队友坐标）都支持：按错一个字母或数字，按一下 ⌫ 删掉它再重打，不用整段重来。距离删空会退回「补第 4 段」那一步。
> Backspace 只在程序等你输入的那几步临时占用，平时照常是系统的退格键。

### 距离超过 100 m：浮窗弹小地图，点一下就能修正目标

测距仪读的 155 m、200 m 只是估测，距离一长，方位差 1° 就能偏出十几米到几十米。所以从 **1.8.3 起**：
第 4 步输完距离，**只要距离 > 100 m**，程序就按你刚才的方位和距离算出敌目标格号，再以它为中心弹一张
**120 m × 120 m 的方形小地图**（底图就是当前地图，33.3 m 一道细网格，比例尺 25 m）。
> 1.8.13 起视野从 100 m 放大到 120 m：**图上 1 px 代表多少米完全没变**（还是 0.4 m 左右），
> 所以小地图窗口也跟着从 272 px 变成 **321 px**，看起来比旧版稍大一圈。只影响望远镜这两条流程；
> 无人机那张 60 m 的仍是原来的 272 px 窗口。

**这张图是「朝向朝上」的**（1.8.4 起）：图的正上方就是你**刚才读的那个方位角**，也就是你的正前方；
你站在图的正下方、绿三角朝上指。所以图上「偏左 10 m」= 你的左边 10 m，「偏上 10 m」= 正前方 10 m，
可以直接照着图判断往哪边挪准星。底图和 33.3 m 网格跟着一起转（不是正北朝上时网格就是斜的）；
图上那个灰蓝色的 **N** 是正北，用来对方向（面朝东时 N 在左边，面朝南时 N 在下方）。

**想按正北看，就按一下方向键「↑」**（1.8.14 起）：小地图弹出来、还没点目标的这段时间里，按一下键盘上那个
**带箭头的「↑」（上下左右那组方向键，不是 W）**，图就立刻转成**正北朝上**——正北跑到图的正上方，
底栏同时变成「上方=正北 · 点目标位置」，其余什么都不变（估测点、绿三角、网格、比例尺、点击、⌫、右键全照旧）。
适合「我要对着地图/队友报的方位看」这种场景；按住不放只转一次，已经正北朝上时再按不会动。
> 只有望远镜那两张图（120 m 视野）响应 ↑；无人机快速定位的 60 m 小地图不响应（它本来就该按机头朝向看）。
> 转成北朝上之后，图上「偏左 10 m」就不再是「你的左边 10 m」了 —— 是按北看的左边。想回到朝向朝上就 ⌫ 重来。

| 图上是什么 | 含义 |
|---|---|
| 正中的青色十字 + 小圈 | 程序**估测**的敌目标（= 你的方位 + 你输的距离） |
| 顶栏 `目标修正 · 估 D3-8-3-8` | 估测点在这个地图上的格号 |
| 底栏 `上方=你的正前方 122° · 点目标位置 · ↑=正北` | 提醒你图的上方是你读的那个方位；`↑=正北` 是说按方向键 ↑ 可以改成北朝上 |
| 绿色小三角（图下方、朝上） | **你自己**：图上正上方是你的正前方，所以你在正下方；太远就贴在下边 |
| 灰蓝色的 **N** | 正北在图的哪个方向（图转过以后唯一的方向参照；按 ↑ 转成北朝上后 N 就在正上方） |
| 鼠标十字（虚线） | 还没点时的瞄准十字，方便你对齐 |

- **点一下目标的真实位置**：图上立刻画一个橙色圈 + 四向刻度，旁边写「偏 12 m」（离估测点多远），
  **1 秒后整个小地图自动消失**，浮窗随即按新的目标重算并照常显示密位 / 方位，状态行写
  「已按小地图修正目标 C12-7-7-1（离估测点 12 m）· 密位 1532.4 mil · 阵地没动」。
- **阵地一点不动**：修正的只是目标，你在地图上点的阵地、之前的射击诸元设置都不受影响。
- **找不到目标**（估测偏得太远，图上没有敌人）：按 **⌫ Backspace** ⇒ 小地图收起、退回第 4 步重新输距离；
  或者直接 **在小地图上点右键** ⇒ 小地图收起，目标保持估测值。
- **窗口位置**：小地图的中心在弹出那一刻**一次性挪到你鼠标所在的位置**（之后不跟着鼠标跑），
  碰到屏幕边缘会自动往里收，所以不会弹到屏幕外；它的十字光标就是点击点，点哪儿算哪儿（1 px ≈ 0.4 m）。
  窗口 321 px 比旧版大 49 px，靠屏幕边缘时会自动往里收，不会有一半在屏幕外。
- **图上量距离**：一格 33.3 m，比例尺 25 m；1 px ≈ 0.4 m（跟 1.8.12 及以前一样，图变大倍率没变）。想微调到 3 m 以内（一个 4 级格）就点准一点。
- **点歪了怎么办**：1 秒内再点一下不算数（第一下就是你要的位置）；等它消失后按 **F8** 重走一遍流程即可。
- 距离 **≤ 100 m 不弹**（这么近估测误差只有一两米，没必要多一步操作）；这时状态行会写
  「（距离 ≤100 m，没弹小地图）」，`run.log` 也会记一行 `[tel] 完成：距离 80 m ≤ 100 m，按规则不弹小地图`。

**图上同时画出这一炮的散布圈（1.13.0 起，半透明亮红）**

小地图一弹出来，就在估测弹着点周围画一个**半透明的亮红色椭圆**，那就是当前这一解（当前武器 + 当前距离/高差 +
当前弹道档）的**落点散布范围**，跟面板上那行「散布 35×34 m」是同一组数：

| 图上是什么 | 含义 |
|---|---|
| 椭圆**横向**半轴（垂直于炮目连线） | `sprA` = 炮口角散布（武器 `moa`）在弹着点横着拉开的距离：`sin(moa) × 初速 × 飞行时间` |
| 椭圆**纵向**半轴（顺着炮目连线） | `sprB` = 高低角差 MOA 那两条边界的**落点距离差**：`|R(θ+moa/2) − R(θ−moa/2)|`，也就是"打远了/打近了"那片 |
| 顶栏 `· 散布 35×34 m` | 面板同一个数，省得你回头找 |
| 椭圆整体朝向 | 长轴顺着**炮位 → 弹着点**的连线；图是"朝向朝上"时这条线基本就是上下方向 |

- 口径与 APK（`Yehorivka-Passability 0.50.0` 的「间瞄武器计算」）一致：那边是 `ctx.ellipse(cx, cy, sprA, sprB, 方位+90°)`
  虚线描边，这里把同一组半轴填成半透明红 + 一圈亮红描边，方便一眼看出"这一发大概会散多大一片"。
- **散布比视野还大时照实画满、不缩放**：60 m 视野里 35 m 半轴的迫击炮，整块图会泛红，这时填充会自动调淡（底图仍看得清）；
  缩了会骗人，宁可让你知道"这一片都可能落"。
- 点一下修正目标后**立刻按新解重画**（那 1 秒里能看到椭圆跟着弹着点一起挪），切武器 / 切低抛高抛 / 改距离也一样。
- **不画的情况**：这组坐标没有解（超射程、超出射界、弹丸寿命外）、目标与阵地重合（< 1 m）、
  以及不是「间瞄火力支援」的图（侦察报告的无人机 / 望远镜小地图、呼叫弹幕分步选点那张）——那些流程有自己的图。

- **弹道被挡时，图上标出「打不到的那片」（1.13.2 起，红色斜线）**

  出诸元的同时，程序会拿**这条弹道真正走的那条抛物线**跟地图数据对一遍：地形（跟解算同一个高程场，
  `map.h_at`）按 ≤2 m 采样比高，建筑 / 桥梁 / 围墙 / 岩石 / 崖壁等立体物与**树木**按「线段 × 有朝向的 3D 盒」求交。
  一旦被挡，浮窗状态行、面板那行说明都会追加 `⚠弹道被挡 699 m · 岩石`，小地图上则多画一层：

  | 图上是什么 | 含义 |
  |---|---|
  | 红底 + 红色斜线的那片（从挡点往外拉的梯形） | **打不到的区域**：弹道在这个方向被挡住，后面的目标修正也没用 |
  | 橙色四边框 | 挡住弹道的那个物体的占地（结构 / 树木挡才有；地形挡只给斜线区） |
  | 黄色 × | 挡点（弹道与障碍相撞的位置） |
  | 红色圆圈 | 你修正过的目标点 —— 它落在斜线区里就说明这一发过不去 |
  | 顶栏 `· 弹道被挡`、底栏 `斜线=打不到 · 点目标位置` | 提醒这一炮需要换阵地 / 换角度 |

  - 挡点跑到视野外（近距离的无人机 60 m 图）时，从图心画一条红色虚线箭头指过去，旁边写「挡 699 m · 岩石」。
  - **不缩放视野骗人**：被挡时小地图会为了同时装下目标和挡点自动放大（上限 420 px 窗口），
    无人机那两张 60 m 的图**不改倍率**（还要用来精确点目标），只叠这层斜线。
  - 另一条角档（低抛 ↔ 高抛）能越过时会写「⚠弹道被挡 … （另一条角档可越过）」，值得切一下试试。
  - **树木也挡弹道（1.13.6）**：树 / 灌木单独存一组盒（`t` 前缀的数组），和建筑盒一样做线段求交。
    盒是整棵树（含树冠）的包围盒，**弹道打进树冠就算挡** —— 穿林、隔着一排树打都会判成挡，偏保守；
    但树**不参与**阵地 / 目标脚下的高度（树干细、树冠不能站人），跟桥面 / 楼顶那套自动抬升完全分开。
    被树挡住时小地图写「挡 137 m · 树木」，和建筑挡一样画斜线区 + 橙框 + 黄 ×。
  - 数据是内置的（`data\los\<图>.npz`，25 张图共 **10.5 MB**、27.8 万个盒 + **145.9 万棵树**），
    **不需要联网也不用你准备素材**；
    这些盒来自 Squad 关卡里的**静态网格实例**（`F:\FModel\SquadAsset\maps\<图>\<图>_struct.npz` 的世界包围盒，
    由 `tools\build_los_pack.py` 量化而来），不是手画的地图，也**不含三角面** —— 所以高度只能取「盒顶」；
    只含**静态关卡物体**，坦克 / 步兵 / 烟雾这类动态东西不算。
  - 判一次约 1–8 ms（树多的图 —— lashkar / yehorivka —— 走满整条弹道时偏上限），跟着解算一起跑，不会卡手。

- **阵地 / 目标高度：站在桥面、楼顶上时自动（或手动）抬高炮位与目标（1.13.3 / 1.13.4）**

  以前炮位高只读地形（`map.h_at`），人站在桥面上、集装箱上时炮位会被低估 2–9 m，高差和密位跟着一起偏。现在出诸元前先看脚下：

  - **自动抬升**只认 **桥面 / 集装箱 / 货箱** —— 这三类人一般是站在盒顶上，盒顶就是脚下地面；
    点位还要落在**内缩 1 m** 后的占地里（盒是偏航包围盒，贴着墙站也会落进盒内），抬升上限 30 m。
  - **盒底必须贴地（离地 ≤1 m）**：素材里只有模型的整块包围盒，没有三角面，所以水塔（盒顶离地 15 m、
    盒底 12.5 m）、架在屋顶上的货箱、桥面以上的栏杆桁架，盒中心都落在下方地面上 —— 这类不参与自动抬升，
    否则人站在塔下会被抬到塔顶（1.13.5 修的就是这个）。
  - **楼体 / 屋顶只提示、不自动抬**：那些盒子是整栋楼的包围盒，人站在一层也会落进盒里，
    自动抬到楼顶会凭空多出 6~22 m，比不修正更糟。这时面板那行写「地形（脚下房屋 9 m，站上去请手填）」。
  - 「诸元」里新增 **阵地高出地面** 输入框（0–40 m，0.5 m 一档）和 **自动** 按钮：自动时框里就是检测值，
    手动改过就以你填的为准（提示变「手动 · 自动+2.8 m」），按「自动」丢掉手动值；
    换阵地 / 换地图自动退回自动判定（手动值不跨点保存）。
  - 抬升同时进 **解算**（`hgun = 地形 + 抬升`）、**弹道遮挡判定**（弹道起点跟着抬高）、
    地图上的「阵地 … m」标签，以及**呼叫弹幕**里每个阵地的诸元。
  - **目标高度同理**（1.13.4 起）：「诸元」里阵地那行下面多了 **目标高出地面**，规则和阵地完全一样 ——
    目标在桥面 / 集装箱 / 货箱上自动抬，在楼顶只写「地形（脚下房屋 9 m，站上去请手填）」，手填的数就是楼顶高度。
    抬升进 **高差 → 诸元**（目标高 2.8 m 就是高差多 2.8 m）、**弹道遮挡判定**（弹道终点跟着抬高，
    "从坡后打楼顶"和"打坡脚"可能一个通一个挡）和地图上的「目标 … m」标签。

  例（自测实测）：yehorivka 桥面 +2.8 m，ZiS-3 打 900 m，密位 66.95 → 63.79；
  同一门炮，目标从平地搬到桥面上，高差 26.3 → 29.1 m、密位跟着变（弹道终点抬高 2.8 m）；
  82 mm 迫击炮 1200 m 上 3 m 只差 3.8 密位（高角弹道对高差不敏感），而直瞄加农炮 800 m 上 3 m 差 3.8 密位 ≈ 170 m 落点。

> 间瞄里弹小地图的是 **望远镜视角**（120 m）与 **无人机快速定位**（60 m，见下一节）；
> 从 1.8.9 起**侦察报告**的无人机 / 望远镜两个子模式也会弹同一套小地图（见「侦察报告」一节里的「小地图修正」）。
### 无人机视角的快速定位：读坐标 + 读方位角 → 弹 60 m 小地图（1.8.6；1.8.16 改了顺序）

无人机的 CURRENT GRID 只给出**目标在哪一格**，读出来的坐标本身就有 3–10 m 的量化误差，
再加上准星对得歪一点，落点就会偏。所以从 **1.8.6 起**，只要面板里框了「方位角区域」，
「快速定位」就变成两步（还是同一个热键，按两次）：

1. **第一次按热键**：**指挥官无人机先截「目标坐标区域」** → 照旧先本地识别、不行才走 AI；
   读到后状态行写「坐标已记，正在读指挥官无人机的方位角（2/2）…」，浮窗提示等方位角。
   （**侦察兵无人机反过来**：第一次先读方位角 —— 它不盘旋，先读后读差别不大。）
2. **第二步自动接着做，不用再按热键**：截「方位角区域」那几位数字 → 走 DeepSeek 读出来
   （例如 `154`）—— 这时的方位角是**刚刚**这一刻的；读到后立刻以目标坐标为心
   弹一张 **60 m × 60 m 的方形小地图**，**图的正上方就是这个方位角**（= 你当时看的方向），
   你在图的正下方、绿三角朝上。网格 20 m 一道、比例尺 10 m，1 px ≈ 0.24 m。
3. **点一下目标的真实位置**：图上画橙色圈 + 四向刻度，旁边写「偏 N m」（离读到的那个坐标多远），
   **1 秒后小地图自动收起**，浮窗按新目标重算、密位 / 方位照常显示，状态行写
   「已按小地图修正目标 C12-7-7-1（离估测点 7 m）· 阵地没动」。

| 情形 | 怎么办 |
|---|---|
| 图上看不到目标（偏太远） | 按 **⌫ Backspace**：小地图收起，再按热键从第一步重来（指挥官无人机 = 重截目标坐标，接着自动再读一次方位角） |
| 不想用小地图 | 在小地图上点**右键**：收起，目标保持读到的那个坐标 |
| 按完热键发现方向不对 | 面板下拉切到另一台无人机（指挥官 / 侦察兵），会重新读那台的方位角；指挥官那边想换一个更新的方位角，小地图还挂着时再按一次热键即可（只重读方位角、坐标保留） |
| 没框方位角区域 | 快速定位退回老行为：截 1 次坐标直接当目标，不弹小地图（也不会报错） |
| 用「准确定位」（F2） | 不变：连截 3 次取外心，不读方位角、不弹小地图 |

- **阵地一点不动**：修正的只是目标，`self.gun` 不动。
- **两台无人机的方位角框分开存**：面板「现在看的是」下拉选「指挥官无人机 / 侦察兵无人机」，
  各框各的、各存各的（`config.json` 里是 `d_region_az_cmd` / `d_region_az_scout`）；
  区域预设也会把这两块一起存下来。
- 方位角那块框**只走 AI、不进本地模板库**：无人机 HUD 是白字 + 粗黑描边、背景是亮地形，
  和望远镜那种细白字完全不是一路，塞进同一个库只会把望远镜的识别带坏。
- 框的时候只框**数字本身**（像 154、283 这种），别把整条罗盘带、刻度线、飞机图标一起框进去。

> 这张 60 m 小地图和望远镜那张 120 m 小地图是同一个窗口，只是视野、网格、比例尺跟着变：
> 120 m 时网格 33.3 m、比例尺 25 m（窗口 321 px）；60 m 时网格 20 m、比例尺 10 m（窗口 272 px）。
> 两张图的**放大倍率不同**：望远镜固定 2.46 px/米，无人机是 4.1 px/米（窗口不变、视野小，所以看着更放得大）。

### 方位角用本地 OCR 读（不再被 1 / 7 认错）

方位角那三个数字 **优先用本地代码认**（约 70–100 ms、离线、不花 API）；本地拿不准才回落到大模型。
这样做是因为大模型在 30×16 px 的小字上偶发把 `1` 读成 `7`，而模板匹配里这两个字形差得很远。

做法（`docr.py`）：

1. 灰度 + LANCZOS 放大 **6× 和 8× 各跑一遍**；
2. 白掩膜（白字黑描边，阈值 = 99 分位亮度 × 0.90，夹在 0.70–0.96）；
3. 列投影切字符（放大后再切，原生分辨率下三个数字会粘成一块）；
4. 按掩膜包围盒裁灰度 → 等比缩放到 32 高 / 26 宽上限 / 左右居中；
5. 与模板库做灰度 **NCC**（允许 ±1 px 平移取最大），每个数字取最高分；
6. 领域约束：方位角**百位只能 0–3**、百位是 3 时**十位只能 0–5**；
7. 三位都要 ≥ 0.85，且**两个尺度必须给出同一串**，否则整次放弃、交给大模型。

模板库是**真机字形**：种子 `data/digit_bank_seed.npz` 来自 9 张人工标注的游戏截图（两个尺度共 51 条）。
运行时存到 `%LOCALAPPDATA%/SquadArtyCalc/digit_bank.npz`（便携版存程序目录），
**大模型每认对一次，就把这张图的字形并进库里**（每个数字、每个尺度各一份，近似重复的自动丢掉），所以越用越准。

实测（9 张真机截图 × 亮度 0.7–1.35 / 对比度 0.8–1.3 / ±3 px 平移，共 81 例）：

| 场景 | 认对 | 放弃（回落 AI） | 认错 |
|---|---|---|---|
| 全库自检（模板含该图） | 71 | 10 | **0** |
| 留一（模板里没有这张图） | 54 | 27 | **0** |

`1` vs `7` 专项：真字形 `1` 对 1 模板 1.000、对 7 模板只有 0.53–0.58；`7` 对 7 是 1.000、对 1 是 0.56。
也就是说：**本地认出来的一定有把握，没把握就交还给 AI，不会硬猜**。

想重新生成种子（比如你多截了一批样图）：

```bat
python tools/build_digit_bank.py
```

（改脚本里 `SAMPLES` 的「目录 / 文件名 / 三位数字」三列即可。）

注意：② 方位角区域请**只框那几个数字**；框歪了、半个数字被切掉时，本地会判「放弃」而不是瞎猜，
这时浮窗会照常用 AI 的结果，状态行写「AI 识别 … ms」；本地成功则写「本地识别」。

### 玩家坐标也用本地 OCR 读（离线、不花 API）

1.8.0 起，**所有模式里读「玩家自己的网格坐标」的地方都先走本地**（1.8.1 修好了「本地每次都放弃」的阈值问题，见下文）：间瞄·无人机视角的快速定位 / 准确定位、
望远镜视角的「玩家坐标」、侦察·无人机视角与侦察兵视角的「队友坐标」，以及侦察的敌目标坐标（格式相同）。
本地认出就直接用（状态行写「本地识别」，0 ms），拿不准才回落到大模型（写「AI 识别 812 ms」）。

做法（`posocr.py`）跟方位角同一套底子，多了「找坐标窗口」这一步：

1. 灰度放大 **5× / 6× / 8× / 10×** 各跑一遍（紧裁图约 85 ms，真实 265×70 截图区约 130 ms）；
2. 白掩膜阈值取 **99.9 分位 × 0.90**（不是方位角那边的 99 分位，见下面的坑），主阈值认不出时
   还会依次放宽到 ×0.95 / ×0.88 再试；
3. 列投影切字；**间距阈值随放大倍数放大**（`max(3, round(up*0.6))`），否则相邻字形会粘成一块；
4. **在字形序列上找坐标窗口**：字母 + 1~2 位行号，然后「短横 + 1 位数字」重复 2~3 次
   （明显比其它字矮的判为短横）。窗口起点可以在任意字形上，**框里多出来的 HUD 文字 / 图标排在窗口外
   就被自动忽略**；同时有多个窗口可用时，优先取「过门槛且段数最多」的（4 级坐标不会被截成 3 级）；
5. 每个字符单独做灰度 NCC（±1 px 平移取最大）；
6. **位置约束**：第一组只能是字母，其余只能是数字 —— 从根上消掉 `I/1`、`O/0` 的混淆；
7. 四个尺度必须给出**同一串**、每位置信度 ≥ 0.90、且第一与第二候选差 ≥ 0.03，否则整次放弃、交给大模型。

**1.8.1 修掉的坑（识图局部失效的真凶）**：原来的阈值用 99 分位，它随「文字占整张图的比例」漂移。
训练样本是紧贴文字的 79×26 裁剪，字占 4~6%，p99 正好落在字芯上；可游戏里框出来的是 265×70，
字只占 ~1%，p99 掉到 0.58~0.64，阈值被压到 0.70 下限，掩膜把字周围的暗边全吃进来、相邻字粘成一团，
于是 `run.log` 里反复出现 `[ocr] kind=pos 本地放弃：… 切出 11 个字、结构不符`，每次都转大模型。
换成 99.9 分位后，紧裁与宽裁的阈值都稳定在 0.99~1.00，宽截图区也能本地认。代价是框里如果有**比字更亮的**
其它 HUD 元素（纯白图标之类），阈值会被抬高、字被吃得只剩细芯 —— 这种情况表现为「本地放弃」，
仍走 AI 兜底，不会认错。

离线实测（26 张真机截图建库，共 296 条模板）：

| 场景 | 认对 | 放弃（回落 AI） | 认错 | 耗时 |
|---|---|---|---|---|
| 原图（26 例） | 26 | 0 | **0** | 84 ms |
| 贴进 265×70 截图区（居中 / 四个角落，各 26 例） | 全部 26 | 0 | **0** | 131 ms |
| 轻微抖动 ±1 px、亮度/对比度 0.9–1.1（104 例） | 92 | 12 | **0** | 92 ms |
| 重抖动 ±2 px、亮度 0.8–1.2、对比度 0.8–1.25（130 例） | 99 | 31 | **0** | 110 ms |
| 分辨率 ×0.75 / ×0.85 / ×1.15 / ×1.3（各 26 例） | 4 / 11 / 14 / 16 | 余下 | **0** | 111–147 ms |
| 265×70 + 额外 HUD 杂项（图标 / 横线 / 别的字，26 例） | 24 | 2 | **0** | 303 ms |

也就是：**认出来的一定对，认不准就直接放弃**。换了游戏窗口大小（分辨率变了）时本地会整批放弃，
由 AI 兜底；AI 每认对一次就把这张图的字形并进模板库（`learn()`），用几次就自愈了。

种子库 `data/position_bank.npz`（296 条，来自 26 张标注截图）可以重建 / 复跑评估：

```bat
python tools/build_position_bank.py
python tools/eval_position_ocr.py
python tools/selftest_position_ocr.py   # 回归自测：紧裁 + 265×70 五种摆位，要求 0 认错
```

### 接口临时失败会自动重试

`vision.py` 把「服务端 5xx / 429 / 请求超时 / 连不上」判成**可重试**：最多 3 次，间隔 0.5 s、1.5 s，
每次重试在 `run.log` 写一行 `[ocr] 接口临时失败（…），0.5s 后重试 1/2`。
401（密钥错）、400（参数错）这类不重试，直接报错。三次都失败才在面板写「识别失败」。

1.8.0 起 `run.log` 还会记清每一次识别的来龙去脉，识图出问题时先看这几行：

```
[ocr] 开始 flow=tel kind=az area=(942, 1048, 34, 21)   ← 按了热键，开始读哪一块
[ocr] kind=pos 本地识别 -> A1-4-1          ← 本地认出来了，不走 AI
[ocr] kind=pos 本地放弃：尺度不一致（5:A1-4-1 / 8:A1-4-7）
[ocr] kind=pos AI 812 ms -> A1-4-1
[ocr] 识别失败：接口返回 503：…
```

1.8.5 起望远镜流程每走一步还写一行 `[tel]`，流程卡在哪一步一眼就能看出来：

```
[tel] 按热键（流程状态 空闲）              ← 收到热键，开始新一轮流程
[tel] 方位角 206° · 本地识别
[tel] 位置读成 F7-2-6（3 段，本地识别）    ← 只读到 3 段 → 停在第 3 步等你补第 4 位
[tel] 补第 4 位 3 → 位置 F7-2-6-3
[tel] 距离第 1 位 = 3（3）
[tel] 完成：距离 300 m · 目标 F8-1-8-3 · 小地图已弹出
[tel] 完成：距离 80 m ≤ 100 m，按规则不弹小地图 · 目标 F8-8-8-3
```

只要日志里**没有** `[tel] 按热键`，就说明热键根本没进程序（被别的软件占用 / 游戏独占输入 / 注册失败看上一行 `[hotkey]`）；
有 `[tel] 位置读成 …（3 段）` 而后面没有 `[tel] 补第 4 位`，就是那一步的数字没按进去。


> **1.2.1 修掉的 bug**：1.2.0 里四块截图区域的「框选结果」没有完全分开 —— 框「侦察方位角」时，框到的矩形被写进了间瞄的「坐标区域」，侦察方位角一直是空的，于是按 F5 就提示「没设侦察方位角区域」。现在四块各存各的（grid / az / r_grid / r_az），面板上每块都显示自己的尺寸与原坐标。1.2.0 留下的错位配置会在启动时自动修正：小而扁的那块会被认成方位角框挪回侦察方位角，间瞄坐标区域按当前预设名还原。

### 侦察报告（先标目标入库，需要时再出报告）

给观察手/队友报点用：先把敌方目标的位置和属性**记进本机目标库**，需要时按报告键选一条，
程序算出「这个目标相对队友在几度方向、多少米」，给一句可以直接发小队的播报句。

**1.5.0 起每个目标都有一个 UID（`T01`–`T50`，同一张图内唯一）**：标记时自动分配，连同型号、坐标一起
复制进剪贴板（`T03 T-72B3 K12-1-8`）；报点、更新位置、清除都带着这个号，队友之间不会把「那辆坦克」说混。
Squad 是 50 v 50，所以一张图最多 50 个号；号用完会提示先清除已经消灭的目标。

**1.4.0 起分成子模式**（面板「侦察报告」分组顶部按钮，截图框、预设、键位各自独立），
**1.6.0 又加了第三个「地图视角」**：

| 子模式 | 怎么拿目标 | 要框几块 |
|---|---|---|
| **无人机视角** | 无人机视角下直接截敌目标 CURRENT GRID（1.8.9 起框了方位角区域就多一步 → 弹 60 m 小地图让你点真实位置；1.8.16 起指挥官无人机是「先坐标、后方位角」，侦察兵仍先方位角；1.8.15 起只读到 3 级坐标也直接弹这张图，不再让人手补第 4 位） | 2 块：指挥官无人机 / 侦察兵无人机 各一块敌目标坐标区域；**可选**再加 1 块方位角区域（复用间瞄那两块） |

**小地图修正（1.8.9 起，两个子模式都有）**

侦察读到目标后，跟间瞄一样**先弹一张小地图让你点出真实位置**，点完再选题入库：

  没填密钥会直接提示，不会静默失败），读到就以目标为心弹 **60 m × 60 m** 小地图、**图的正上方 = 那个方位角**，
  你在图的正下方、绿三角朝上；网格 20 m、比例尺 10 m、1 px ≈ 0.24 m。
  **没框方位角区域就退回老样子**：一次读完坐标、直接进选题，不弹图。
- **侦察 · 望远镜视角**：方位角 → 你的坐标 → 输 3 位距离，**距离 > 100 m** 才弹 **120 m × 120 m**

- **⌫ Backspace**：小地图收起、退回上一步 —— 无人机只重截目标坐标（方位角保留），
  望远镜退回重输距离；**右键**：收起，目标保持读到的那个坐标。
- **只读到 3 级坐标时也弹这张图（1.8.15 起）**：无人机视角读到 `K12-1-8`（3 段）不再停下等你补第 4 位，
  直接以这个 3 级格心为心弹 60 m 小地图（框了方位角框就还是上方 = 方位角，没框就是正北朝上）；
  点完那一下按**最终坐标**倒算出 **4 级格号，只用来看和写进播报句**，
  目标库里记的 `rx/rz` 与之后报告里的方位 / 距离都用**点出来的原始坐标**（不再被 3.7 m 子格量化）。
  不点就按 ⌫ 取消，退回「再按标记键重截坐标」，方位角保留；右键也一样。
- **标记新目标**与**更新已有目标的位置**两条路都会弹（1.8.10 起）：
  标记 → 点一下修正后照旧「选分类 → 选型号 → 入库」；

  「点小地图修正目标 · 格号」，改完状态行写「已更新目标位置：… · 小地图修正 N m」。
- **更新这条路「不点 = 取消」**（1.8.10）：图上不点就右键 / 按 ⌫ / 切模式 / 切子模式 / 按报告键或清除键，

  无人机退回「再按一次标记键重截目标坐标」（方位角保留）、望远镜退回「重新输 3 位距离」，
  状态行明写「这条记录还没改」。所以「更新位置」不会在你没点的情况下悄悄改库。
- 地图视角的「更新位置」不弹（没有方位角，直接键格号改）。望远镜这条路同样是**距离 > 100 m 才弹**。
- 无人机那两个方位角框**和间瞄共用**（面板「侦察报告」分组里新增了「框选方位角（当前无人机）」
  与「预览」两个按钮，选哪台就框哪块，存的还是 `d_region_az_cmd` / `d_region_az_scout`），
  同一台无人机的 HUD 位置一样，不用框两遍；区域预设也会一起存。

**标记（地图视角 · 不截图，直接键格号）**

从队友 / 指挥频道拿到的格号，或者自己看地图算出来的格号，可以直接敲进去，全程不截图：

| 步骤 | 你要做的 | 浮窗提示 |
|---|---|---|
| 0 | 按一次 **F5** 先选 **1 标记新目标**（库不空时还有 **2 更新已有目标的位置**） | 标记方式：1 新目标 / 2 更新已有 / 0 取消 |
| 1 | 键 4 级格号共 6 个字符：字母 + 2 位行号 + 3 位子格。`K12-1-8-8` 就敲 `K 1 2 1 8 8`（`K7` 要敲成 `K07`） | 格号 K12-1-8 · 再输 1 位（共 6 位，例 K12-1-8-8） |
| 2 | 敲错了按 **⌫** 删一位（也可以直接按标记键，没输满会提示还差几位） | 已删一位 → 格号 K12-1 · 再输 2 位 |
| 3 | 输满 6 位后**再按一次标记键**确认（浮窗「目标」行会先把格号显示出来） | 格号 K12-1-8-8 —— 按 F5 确认；敲错了按退格删一位 |
| 4 | 和别的子模式一样：选分类 → 选型号 → 入库分配 UID、复制 `T01 T-72B3 K12-1-8-8` | 目标 K12-1-8-8 · 这是哪种敌方目标？ |

- 数字**主键盘和小键盘都认**（不用管 NumLock 亮不亮，主键盘那排数字照样能打）；字母用主键盘。
- 格号不在本图范围内（比如从别的地图抄来的）会直接提示「`Z99-9-9-9` 不在这张地图上（图幅 6350×6350 m）」，
  停在输入状态，退格改一下就能继续。
- 输满 6 位之后再按数字不会把格号搞乱（会提示「已经输满 6 位，按 F5 确认 / 退格改」）。
- 报告、更新位置、清除目标跟另外两个子模式**完全一样**（报点仍然要连打队友的 4 级坐标）。

**更新已有目标的位置**

同一个目标挪了地方（或者第一次标歪了）：按 **F5** → 浮窗选 **2 更新已有目标的位置** → 列出这张图的
目标（`T01 T-72B3 · K12-1-8`，8 条/页，9 = 下一页）→ 按数字选一个 → 用当前子模式的原流程重新截坐标
（无人机视角直接截；望远镜视角走方位角 → 你的坐标 → 距离）。
只改坐标，**UID 与型号/血量/票数都不变**，剪贴板更新成 `T01 T-72B3 K13-5-7`，状态行写「已更新目标位置」。

1.8.10 起，读到坐标后会**先弹小地图让你点目标的真实位置**（跟标记新目标同一张图：无人机 60 m / 望远镜 120 m，
上方 = 方位角）：**点一下才更新这条记录**（只改坐标），图上会画橙圈 + 「偏 N m」并 1 秒后自动收起；
**不点就取消** —— 右键、按 ⌫、切模式或子模式、按报告键 / 清除键都算放弃，目标库一个字都不动，
状态行写「这条记录还没改」，退回能重来的那一步（望远镜退回重输距离，无人机退回重截坐标）。
望远镜这条路同样是距离 > 100 m 才弹；地图视角「更新位置」不弹。

**清除目标（消灭了才清）**

1. 按 **F6**（面板「清除侦察目标」按钮同效）：浮窗问 **1 选择要清除的目标 / 2 全部清除 / 0 取消**。
2. 选 1 → 列出本图目标，按 1–8 **逐个选中/取消**（选中的前面有 ●），9 = 下一页；按 **0 = 确认清除**。
3. 选 2 → 弹框二次确认「把这张图上的 N 个目标全部清除？」。
4. **清除动作发生之前**，程序先把这句复制进剪贴板：
   `T-72B3 T01 已经被消灭；BMP-1AM T02 已经被消灭；`（一行一个目标，句尾带分号），
   然后才删记录——直接粘到小队频道就能报战果。
5. 清完 UID 会重新变空：下次标记新目标又从最小的空号开始（T01、T02…）。

**报告**

1. 按 **F11**（面板「报告」按钮同效）：浮窗列出**这张图的目标**（按 UID 排：`T01 T-72B3 · K12-1-8`，
   8 条/页，9 = 下一页），按数字选；0 = 取消。
2. 连打队友的 4 级坐标：`B11-2-5-6` 就敲 `B 1 1 2 5 6`（字母主键盘、数字小键盘），第 6 位打完自动算。
3. 剪贴板里是整句播报（带 UID）：
   `队友B11-2-5-6，有敌人（T-72B3 T01）在你的100度方向，2696米处，坐标K13-5-7`
4. 浮窗（无人机视角）：**模式** / **目标**（格号 · 型号 · UID）/ **队友看**（方位° · 距离 m）/ **队友**；
   望远镜视角另加 **我** 与 **我测得**（方位° · 距离 m）。
5. 报告过的记录会在库里标 `reported=1`，记录本身保留，可反复报给不同队友。

**目标库**

- 存 `targets.db`（sqlite，和 config.json 同目录：便携版在程序目录，程序目录不可写时在
  `%LOCALAPPDATA%\SquadArtyCalc\targets.db`）。
- 每条记录：**UID（`T01`–`T50`）** / 格号 / 米制坐标 / 高程 / 阵营 / 分类 / 型号 / 血量 / 票数 / 来源子模式 / 时间 / 是否报过。
- UID 号池**按图独立**：每张图都是 T01 起，删掉一个号下次就复用这个号（Squad 一局 50 人，所以上限 50）。
- 老版本（1.4.x）留下的记录会在启动时自动补 UID（按入库时间排 T01、T02…），不用手动迁移。
- 面板「目标库：本图 N 条 · 按 F11 报告」，右边「清空目标库」会二次确认，只清当前这张图；
  平时清单个目标用 F6 那套（它会先复制消灭通报，这个按钮不会）。
- 记录**按地图分开**：换图后 F11 只列这张图的记录。
- 队友坐标**第一段 3 个字符**：`B11`、`B07`（`B7` 要打成 `B07`），后三段各一位、只能是 1–9。
- 等队友坐标时临时占用 A–Z 与小键盘 0–9，输满 6 位自动注销；字母用主键盘，数字用右侧小键盘（NumLock 亮）。
- 目标点是**截出来的坐标**（无人机视角）或「你的坐标 + 方位 + 距离」推算的（望远镜视角），
  望远镜那边距离要报准：距离差 10 m，目标就偏 10 m。

### 发布命令（指挥小队，第三个模式）

面板「模式」里点 **「发布命令」**，先在上面两个下拉里选好 **我方阵营** 与 **部队**（必须细到具体部队，
比如「美军 · 1st Infantry Division（合成兵种）」）——「建造」可选的工事与武器就来自这套编制，
换阵营/部队会清空正在输入的命令。这套配置会存进 config，下次打开还在。热键三行：

| 键 | 默认 | 作用 |
|---|---|---|
| 发布命令 / 确认 | Alt+F12 | 开始一条新命令；每一步输入完按它确认 |
| 取消已输入的内容 | Alt+Shift+F12 | 整条命令作废，重新从队长开始 |
| 浮窗显隐 | Ctrl+F12 | 显示 / 隐藏浮窗 |

按 Alt+F12 开始后走四步，每一步都用右侧小键盘输数字、按 Alt+F12 确认（⌫ 退格删上一位）：

1. **谁**：1–2 位队长编号（`1`…`99`），同一条命令只呼一个队长。
2. **去哪里行动**：6 字符的 4 级格号 —— 1 个字母 + 2 位行号 + 3 位子格。行号不足两位要补 0，
   例如 `G7` 必须打成 `G07536`（面板上显示成 `G07-5-3-6`）；数字键主键盘/小键盘都认，字母用主键盘。
3. **干什么事情**：`1` 观察 · `2` 移动 · `3` 进攻 · `4` 防守 · `5` 建造 · `6` 打火力支援标 · `7` 放电台 · `8` 放队包。
   选 **建造** 会再让你选一层：
   - 类别：`1` 功能性建筑 · `2` 防御工事 · `3` 武器
   - 具体项：按当前部队的编制列出（带造价与数量上限），每页 8 个，`9` 下一页、`0` 返回类别。
     功能性建筑固定是 兵站（屯兵所）/ 弹药箱 / 维修站 三项。
4. **态度**：`1` 立即执行 · `2` 完成手里的事情再执行。

最后按 Alt+F12 确认，程序把整句复制进剪贴板并显示在浮窗，例如
`2队长，你去G07-5-3-6执行建造HESCO 掩体任务，立即执行`。
切回游戏在小队频道 `Ctrl+V` 就能发出去；再按 Alt+F12 直接开下一条。

> **键被抢了怎么办**：全局热键是先注册先得 —— Steam 的截图键（默认 F12）、SquadShot（默认 F8）、
> 语音/录屏工具都会抢。所以「发布命令」的默认键特意避开 F12，用 `Alt+F12` / `Alt+Shift+F12`。
> 万一还是被占，「发布命令」分组里会多出一行红字
> 「⚠ 「Alt+F12」被别的程序占用了（错误码 1409）：按下它不会到本程序」。
> 点三个键位框，直接按下你想换的组合即可（例如 `Ctrl+F9`）；
> 换键之前，面板上的「发布命令 / 确认」「取消已输入的内容」「浮窗显隐」三个按钮照样能用。

### 呼叫弹幕（几门迫击炮排一条线往前推，第四个模式，1.8.17）

面板「模式」里点 **「呼叫弹幕」**。这个模式不读你当下的阵地，而是先用一个**阵地库**（最多 15 门）记住
「哪几门迫击炮摆在哪个坐标」，每次呼叫时勾选参与的那几门；起始点 + 宽度 + 方向 + 推进速度都由你在小地图上点，
程序排出每一轮、每一门要打的目标点，把密位 / 方位算好，整段抄进剪贴板。

**① 先建阵地库**（面板「呼叫弹幕」块）

- 「新建阵地」：UID 自动给空号（B01…B15），填名称与武器
  （weapons.json 里的，迫击炮类是 FOB 81mm / M252 这些）。
- 坐标怎么来：面板「地图与武器 → 阵地库」下拉默认是 **「手动点地图」** —— 在地图上点一下就把那个点记住，
  「新建阵地」直接拿它当坐标（只问名称与武器，不再弹坐标框）；下拉里选了**某个具体阵地**时，在地图上点一下 =
  **把那门炮挪过去**（状态栏会说「阵地 B01（村口）已挪到 …」），要改坐标走这条最快。
  没点过地图 / 下拉选着具体阵地时，`新建 / 修改` 仍会弹坐标输入框，可以手打 3 级或 4 级格号。
- 列表每行前面有勾选框：**勾上的才参与这次弹幕**（上限 15 门）。
- 「修改」「删除」作用在列表里选中的那条；阵地库存在 config.json 的 `bar_positions`，下次打开还在。

**② 一次呼叫 = 四步（第一步里还多一下「修正起始点」，1.8.18），宽度和方向都在同一张小地图上点，中间不关窗口**

| 步 | 做什么 | 怎么操作 |
|---|---|---|
| 1 | 标起始点 | 按流程键（默认 `Ctrl+F1`）。无人机视角 = 读屏幕上 CURRENT GRID 的坐标；望远镜视角 = 老流程「方位角 → 你的坐标 → 3 位距离」，起始点 = 你的坐标 + 距离 × 方位 |
| 1b | 修正起始点（1.8.18） | 读完就弹一张小地图（以识别值为心，**上方=方位角**，1.8.20 起；读不到方位角时正北朝上）：**点一下起始点的真实位置**，起始点立刻换成点出来的坐标，图不关、直接进下一步定宽度；鼠标停在哪还会显示「偏 N m」。识别值本来就准的话**不用点**，直接点宽度就行（那就按识别值走） |
| 2 | 定宽度 | 与上一步是同一张图、不关窗口（**上方仍是你第一步的方位角**，1.8.20 起；望远镜视角可按一下方向键 ↑ 转成正北朝上）。在起始点**一侧点一下**：起始线关于起始点对称，宽度 = 2 × 你到起始点的距离，钳在 10 m 到 10 m × 门数 |
| 3 | 定方向 + 推进距离 | 在起始线**某一侧再点一下**：点哪边就往哪边推，推进距离 = 你到起始线的垂直距离（至少 5 m） |
| 4 | 输推进速度 | 小键盘或主键盘输数字（米/轮，**≥ 10**），按流程键确认 → 弹出「第 k/N 轮」诸元表，同时复制进剪贴板 |

宽度按门数等分（每门管自己那一段的中点，所以每门正面 ≤ 10 m），第 k 轮整体沿方向推进 `(k-1) × speed` 米，
轮数 = `floor(深度 / speed) + 1`。每一行长这样：

```
第 1/2 轮 · 目标线离起始线 0 m
B01 · FOB 81mm 迫击炮 · M821A1 · 密位 1485.4 mil · 方位 64.7° · 277 m
B02 · FOB 81mm 迫击炮 · M821A1 · 密位 1480.8 mil · 方位 56.3° · 288 m
```

**③ 热键**（面板「呼叫弹幕」块里三行都能改，改法与其它模式一样）

| 键 | 默认 | 作用 |
|---|---|---|
| 弹幕流程 / 确认 | Ctrl+F1 | 标起始点；输完速度按它出诸元；已经出诸元时按它 = 下一轮 |
| 清除弹幕 | Ctrl+Shift+F1 | 整次作废，退回标起始点 |
| 浮窗显隐 | Ctrl+Alt+F1 | 显示 / 隐藏浮窗 |

- 修正起始点这一步按 ⌫ / 右键 / 关掉小地图 = 取消这次弹幕；已经修正过再点宽度不会把起始点改回去。
- **小地图的上方 = 你这次的方位角**（1.8.20 起）：无人机视角会在读完坐标后**自动再读一次无人机方位角**（用面板里「间瞄火力支援 · 无人机视角」那两块方位角框，指挥官/侦察兵各一块），望远镜视角直接用第一步读到的方位角。望远镜那张图（120 m）里按一下**方向键「↑」**就把正北转到上方，底栏会写「上方=正北」；点完宽度再点方向，朝向不会被弹回去。无人机那张（60–200 m）不响应 ↑。没框方位角区域、或方位角没读出来（接口报错 / 没填密钥）时，小地图按**正北朝上**弹出来，流程照常往下走。
- **浮窗里也直接显示这一轮的每门诸元**（1.8.19 起）：浮窗下半区是「诸元 · 离起始线 N m」+ 每门一行「B01 密位 1485.4 mil · 方位 64.7° · 277 m」，混装武器时那一门自动写「射角」；打不到的门标红写「打不到（超出射界）」。有诸元块时浮窗会加宽到 430 px，嫌挡视线按 `Ctrl+Alt+F1` 收起来。
- 「上一轮 / 下一轮 / 复制本轮 / 清除」面板上也有按钮；浮窗和面板同时显示当前这一轮。
- ⌫：定宽度 / 定方向 / 输速度时 = 放弃这次弹幕；已经出诸元时 = 清掉结果。
- 小地图被关掉（右键、切模式、切子模式）也是取消，得按流程键重来。
- 每门用的是**自己那条阵地登记时选的武器**，同一个阵地库里混装不同炮、不同口径都可以，诸元按各自武器算。

> 为什么宽度方向都要在小地图上点：这张图是正北朝上、真实米制的（比例尺 25 m / 网格 33.3 m），
> 视野按门数自动放到 120 到 200 m，你照着游戏里看到的正面宽度点两下就行，不用心算。

## 四、演练（不用开游戏就能自测）

「演练（假 HUD，端到端自测）」会在你框好的 ① 坐标区域里摆一块假 CURRENT GRID（随机格号）、
在 ② 方位角区域里摆一个随机方位角数字（勾了望远镜流程时正好能一次走完四步），
这时按快速定位键（或准确定位键连按 3 次），程序截真屏 → 走真接口 → 出真结果。用来确认密钥、区域、识别链路都通，
再进游戏。演练窗关掉即恢复。

切到「侦察报告」模式后，演练改用侦察模式当前子模式的框：无人机视角摆随机格号的敌目标坐标，
望远镜视角摆随机格号 + 随机方位角。按 **F5** 就能走一遍完整侦察流程
（数字记得用小键盘），再到浮窗里按数字选题入库、按 **F11** 出报告。

## 六、界面小说明

- 「地图」「武器」两个下拉列表是**深底白字**，展开后每项都可直接读（早期版本出现过黑底黑字）。
- 武器下面一行是 **「弹道」三档（自动 / 低抛 / 高抛）**（1.12.0 起）：只影响「间瞄火力支援」取哪一支解——
  **自动**跟以前一样按武器自己的习惯（`weapons.json` 的 `ang`：迫击炮 / 榴弹炮走高抛，火箭巢 / 车载炮 / 榴弹发射器走低抛）；
  **低抛**只要平射那一支、**高抛**只要大仰角那一支。选中的强制档打不了（超射界 / 弹丸寿命外 / 弹道无解）时
  状态行直接报「低抛弹道打不了（超出射界 45–88.875°）· 这组距离只有高抛解」，**不会偷偷换成另一端**——
  点了低抛却拿到高抛的密位比报个错危险得多。选择记在 `config.json` 的 `arc` 字段，下次启动还在；
  「呼叫弹幕」批量算诸元不受它影响（仍按自动），免得在间瞄里选了低抛之后弹幕诸元全变红。
  典型用法：M1064 / BM-21 这种两支解都能打的炮，点**高抛**能拿到大仰角诸元（越过前方掩体），
  点**低抛**飞行时间更短；迫击炮本身只有高抛解，点低抛就会看到上面那句提示。
- 热键按子模式分行：**无人机视角** 四行（快速定位 / 准确定位 / 清除坐标 / 浮窗显隐）、
  **望远镜视角** 三行（望远镜流程 / 清除望远镜 / 浮窗显隐）、
  **侦察报告** 四行（标记 / 下一步 · 报告 · 清除侦察目标 / 浮窗显隐）。
  **改键 = 点一下右边输入框，按下新键即可**（Esc 或点别处结束输入）。输入框里就是当前生效的键。
- 右侧面板内容较长，窗口比屏幕矮时会**自动出现滚动条**，底部「退出程序」始终固定可见。
- 窗口打开时会自动按屏幕可用区域缩放并居中，不会把底部按钮挤到任务栏下面。
- 浮窗内容**跟着当前大模式走**，切模式时立刻换成本模式的内容，不会残留上一个模式的数字：
  间瞄 = **阵地 / 目标 / 角度 / 方位** 四行（角度那一行的标题随武器变：迫击炮写「密位」，有射角的武器写「射角」）；
  侦察 = 模式 / 目标 / 队友看 / 队友（需要选目标时再加编号列表）；
  发布命令 = 我方 / 进度 / 已输入 三行，出过命令后显示上一条整句（自动换行）。
- 间瞄那四行数值从上到下固定是：**阵地 → 目标 → 角度 → 方位**（方位永远在最底下一行），
  等宽字体一眼扫读；状态行颜色：黄=算着呢、绿=成了、红=失败/打不到。
- 第三行「角度」**跟着当前武器走**（1.8.2 起）：`unit` 是 `mil` 的（FOB 81mm 迫击炮、SuperMod MO120RTF1 系列）
  标题写「密位」、值写 `1353.09 mil`；`unit` 是 `deg` / `degMin` 的（UB-32、Hell Cannon、BM-21、Mk19、
  M1064 M121、BTR-4 AGS-30、PZL07、M109、M777…）标题写「射角」、值写 `6.71°` / `3°27.55′`。
  换武器时主面板标签、浮窗第三行、状态行（「高角**密位** 1353.09 mil」/「低角**射角** 6.71°」）一起换；
  剪贴板也是「密位 1353.09 方位 63.9°」或「射角 6.71° 方位 63.9°」。
  **1.11.0 起角度一律保留 2 位小数**（方位仍 1 位）；本文档 1.11.0 之前写下的输出示例仍是当时的 1 位。
- 「**截图区域 · 无人机视角**」分组（drone 子模式）从上到下是：

## 七、已知限制 / 注意

- **AI 会把字母读错**：实测出现过把 `I12-6-2` 读成 `L12-6-2`。程序对以 I 开头的坐标会加一句提醒，但
  重要目标建议自己扫一眼格号。
- 识别区域里**不要有别的文字**（聊天框、击杀提示、载具名），否则容易读串。
- **独占全屏（Fullscreen）模式下浮窗可能被盖住**，请把游戏设成「无边框窗口（Borderless）」。
- 热键被别的程序占用时（控制台打印「注册失败，错误码 1409」，面板提示行变红），
  换一个键，或先用面板上的按钮顶着；只影响被占的那一个功能。
  **发布命令**的三个键也可能被截图工具抢（Steam 默认 F12，默认键已避开它）：出现红字时，
  到「发布命令」分组点三个键位框换成别的组合即可。
- **单文件 exe 启动要解包**：1.8.8 起 498 MB 里有 444 MB 地图，双击后约 6~8 秒才见窗口，属正常现象；

**两个必然遇到的坑（提前说清楚，省得以为是程序坏了）**

- Windows SmartScreen / 杀软会拦：程序没做代码签名，提示「未知发布者」时点「更多信息 → 仍要运行」。
  杀软报毒多半是 PyInstaller 单文件的自解压特征，把它加进信任即可。
- **F1 很可能已经被别的软件占了**（Snipaste 的截图键默认就是 F1，本机实测就是它）。
  这时面板热键行会变红提示「注册失败（错误码 1409）」，点右边输入框按个新键即可，
  比如 F5/F9 或 Ctrl+Shift+1；F2/F3/F4 各自独立，只影响被占的那一个。
- 同一个 exe 开第二个实例会弹「已经在运行」——两个实例会互抢全局热键，所以直接拦住。

**自己重新打包**（改了源码之后）：

```
cd D:\mil-ai\IFC\ArtyCalc
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
  --name "Squad间瞄火力助手" --icon "%CD%\app.ico" --version-file "%CD%\build\version_info.txt" ^
  --add-data "%CD%\build\datapack;data" ^
  --add-data "%CD%\dist\mapsdb;mapsdb" ^
  --exclude-module tkinter --exclude-module PySide6.QtQml --exclude-module PySide6.QtQuick ^
  --exclude-module PySide6.QtNetwork --exclude-module PySide6.QtOpenGL --exclude-module PySide6.QtTest ^

```

> 这段是 **cmd** 语法（`^` 续行）；用 PowerShell 的话把每行末尾 `^` 去掉、拼成一行再跑。
> 路径都用了 `%CD%`：给 `--specpath` 时 PyInstaller 会把 spec 里相对路径按 spec 所在目录解析，
> 不改绝对路径会报「Unable to find ...\build\data」。

1.8.7 起 `data\` 只打包 json / npz：打包前先把它们**复制到一个 staging 目录**
（`build\datapack`，约 0.6 MB，不含 `maps` 子目录），用 `--add-data "…\build\datapack;data"`；
1.8.8 起**地图也进 exe**：先用 `python tools\build_mapdb.py --src D:\mil-ai\combat_ai\maps --dst "dist\mapsdb"`
生成地图库（约 444 MB），再 `--add-data "…\dist\mapsdb;mapsdb"`。
打包前记得先关掉正在跑的助手（`Get-Process '*Squad*' | Stop-Process -Force`），否则覆盖 exe 会报
`PermissionError: [WinError 5] 拒绝访问`。

体积为什么这么大：地图约 444 MB（8192² JPEG 本来就压不下来多少）+ PySide6 的 Qt 运行库约 60 MB
+ Python 运行时。想瘦身：把地图库换成 4096² 或只留 `_lo` 的小库（见第三章「想换库 / 想瘦身」），
或者干脆走 1.8.7 那种「exe + 旁边的 mapsdb 目录」的分发方式（查找顺序里程序目录\mapsdb 优先，仍然支持）。
